## שחזור

- `npm test` — בדיקות הקוד, ללא תלות ברשת וללא חבילות חיצוניות.
- `npm run test:deployed` — בדיקות HTTPS מול הפריסה הפעילה.
- `npm run test:live` — בדיקות HTTP חדשות מול מקור הנתונים והעברת התשובות בסימולציה המקומית.
