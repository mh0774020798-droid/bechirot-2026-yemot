# קו עדכוני בחירות 2026 — התקנה בשלוחה הראשית

## מצב החדשות בשלוחה 1

שלוחה 1 הופרדה מאחוזי ההצבעה ומחוברת כעת למנגנון חדשות מהאתר. המקור `https://bechirot.onrender.com/data/news.json` מחזיר כרגע `401` עם `login required`. כדי לקבל חדשות אמיתיות נדרשת כתובת JSON מורשית מאתר המקור. עד לקבלת גישה השלוחה משמיעה שהעדכונים אינם זמינים.

מנגנון העיבוד מוכן לשלושת המקורות שנבחרו: ערוץ 14, ינון מגל ועמית סגל. כל עדכון כולל שעת פרסום בשעון ישראל, שם המקור ותקציר. לדוגמה סינתטית לצורכי בדיקה: "עשר בערב מערוץ ינון מגל, הודעת בדיקה". נבחרים עד ארבעה עדכונים לכל מקור מהיממה האחרונה, בסדר מהחדש לישן וללא כפילויות.

את הכתובת המורשית מגדירים ב־`NEWS_DATA_URL`. אם ספק האתר מסר כותרת Authorization מורשית, שומרים את ערכה כ־secret בשם `NEWS_AUTHORIZATION`, מחוץ למאגר. הקורא מוגבל למקור `bechirot.onrender.com`, אינו עוקב אחר הפניות ואינו מנסה לעקוף התחברות.

## תיקון שלוחה 5

בתשובת הרשימות היו מרכאות ASCII ולוכסני escape בתוך שמות הרשימות. ה־Worker מנקה אותם לאחר אימות הפרוטוקול ובודק את התוצאה שוב. התשובה נבדקה ב־GET וב־POST עם זיהוי הלקוח של ימות; עדיין נדרשת האזנה בשיחת טלפון אמיתית.


התפריט מותקן **בשלוחה הראשית `/`**, ושלוחות התוכן הן **`/1` עד `/5` ישירות תחתיה**. ה־Worker כבר נפרס עבור המבנה הזה ומחובר לסקריפט Google הקיים.

[כתובת תפריט הבחירות](https://elections-2026-yemot.mh0774020798.workers.dev/menu) · [בדיקת החיבור](https://elections-2026-yemot.mh0774020798.workers.dev/health)

## מיקום הקבצים בימות

התיקייה `yemot` בפרויקט משקפת את המבנה במערכת הטלפונית:

| הקובץ בפרויקט | מיקום בימות | תוכן | סיומת הכתובת ב־Worker |
|---|---|---|---|
| `yemot/ext.ini` | השלוחה הראשית `/` | תפריט הבחירות | `/menu` |
| `yemot/1/ext.ini` | `/1` | עדכונים מערוץ 14, ינון מגל ועמית סגל | `/summary` |
| `yemot/2/ext.ini` | `/2` | אחוזי הצבעה | `/turnout` |
| `yemot/3/ext.ini` | `/3` | מדגמים | `/exitpolls` |
| `yemot/4/ext.ini` | `/4` | תוצאות אמת | `/results` |
| `yemot/5/ext.ini` | `/5` | רשימות ואותיות הפתק | `/parties` |

העתק כל קובץ לשלוחה התואמת. אם כבר התקנת את שלוחות 1–5 ישירות תחת הראשית עם הכתובות האלה, מבנה השלוחות מתאים לפריסה המעודכנת.

הקובץ בשלוחה הראשית כולל:

```ini
type=api
api_link=https://elections-2026-yemot.mh0774020798.workers.dev/menu
api_url_post=yes
api_hangup_send=no
```

מומלץ להעתיק את הקובץ המלא המצורף, שכולל גם קול והגדרות שליחת פרטים. אין צורך בקובץ הקלטת תפריט: השרת מחזיר פקודת `read` המקריאה את האפשרויות ומקבלת בחירה.

## ניווט

מקשים 1–5 בתפריט מפנים לשלוחות `/1` עד `/5`. בסיום כל הקראה חוזרים ל־`/`. מקשים 0 או 9 בתפריט מחזירים לתפריט הראשי; בהקראה מוסבר שמקש 0 משמיע את התפריט מחדש.

התיקון נעשה ב־Cloudflare, ואין צורך לערוך או לפרוס מחדש את Google Apps Script שכבר חיברת. כתובות ה־API נשארו כפי שהן. `YEMOT_ROOT` מוגדר כעת ל־`/` ב־Worker וב־`wrangler.toml`.

אם מתקינים בעתיד תחת שלוחה מספרית, למשל `/7`, יש לשנות את `YEMOT_ROOT` ב־Worker לנתיב המתאים ולהעתיק את תוכן תיקיית `yemot` אל אותה שלוחה. סדר שלוחות התוכן נשאר 1–5.

| הקשת 1–5 בנפרד | התוכן המתאים וחזרה לתפריט הראשי |

`WORKER` הוא `https://elections-2026-yemot.mh0774020798.workers.dev`.

`/health` בודק את התקשורת עם Google ואת גיל המטמון. הוא אינו אישור שהנתונים במקור התעדכנו עכשיו. בדיקת HTTP אינה מחליפה חיוג ואימות השמע בימות.

## איך התוכן מתעדכן

נתוני שלוחות 2–5 ממשיכים לעבור מימות דרך Cloudflare אל Google Apps Script, שקורא את כתובות הטקסט החיות המתועדות במאגר המקור. חדשות שלוחה 1 נקראות מקובץ החדשות של אותו אתר, לאחר מתן גישה מורשית. לכל נושא יש מטמון קצר של 30 שניות, והרענון נעשה בעת כניסה לשלוחת התוכן. אין צורך בתזמון, Google Drive או טוקן ניהול של ימות.

בכשל של המקור ניתן להשמיע עותק שהתקבל לפני עד חמש דקות, עם הודעה מפורשת שמדובר בעותק קודם. בלי עותק זמין מושמעת הודעת תקלה וחוזרים לתפריט הראשי. קצב הפרסום והזמינות של הנתונים תלויים במקור ובמכסות השירותים.

הקוד מתאים נקודות ומקפים לפרוטוקול של ימות, מחלק טקסט ארוך למקטעים ושומר את הקרדיט למקור. אין בו חישוב עצמאי של תוצאות בחירות.

## בדיקות הקוד והפריסה

נדרש Node.js 20 ומעלה. אין חבילות npm חיצוניות.

```bash
npm test
npm run test:live
npm run test:deployed
```

- `npm test` בודק את הקוד, המטמון, הפרוטוקול וההפניות, כולל הפניות מהשלוחה הראשית ותאימות לפריסת Google הקיימת.
- `npm run test:live` בודק את ארבע כתובות מקור נתוני הבחירות ומשלב את התשובות בסימולציה מקומית.
- `npm run test:deployed` בודק את הפריסה הציבורית בפועל. חסימת גישה לחדשות מדווחת כחסימה, ולא כהצלחת קריאת חדשות. ברירת המחדל היא `YEMOT_ROOT=/`; לבדיקת התקנה אחרת אפשר לספק את המשתנה `YEMOT_ROOT` לסקריפט.

תוצאות הבדיקות מתועדות ב־`TEST-REPORT-HE.md` ובתיקיית `evidence`. בדיקת הפריסה משתמשת בזיהוי לקוח מפורש לפי [הנחיות Cloudflare ללקוחות API ב־workers.dev](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/).

## יצירת פריסה חדשה

הפריסה המחוברת כבר פעילה. בהקמה חדשה, הדבק את `Code.gs` בפרויקט Google Apps Script חדש, הפעל `runSelfTests` ו־`testLiveSources`, ופרוס כאפליקציית אינטרנט עם ביצוע בתור הבעלים וגישה של "כל אחד". שמור את כתובת `/exec`.

פרוס יחד את שני קובצי ה־Worker, `worker.js` ו־`news.js`, והגדר `GOOGLE_SCRIPT_URL` לכתובת הזו ו־`YEMOT_ROOT=/`, ופרוס. אפשר להשתמש גם ב־`wrangler.toml`, הכולל את הגדרות הפריסה הנוכחית. לאחר מכן עדכן את כתובות ה־Worker בששת קובצי `ext.ini` אם השתמשת בשם Worker אחר.
